2. Open the project folder.
3. Ensure `index.html`, `style.css`, the `images` folder, and the resume PDF are present.
4. Open `index.html` in a web browser, or use the Live Server extension in Visual Studio Code.

No Python environment or `requirements.txt` file is required to run this HTML and CSS portfolio.
